## 1、任务与任务间资源

对于 **任务间共享变量**，不需要任何锁或开关中断等操作，因为协程是相互协作的，一个任务在主动出让之前都不会被其它任务抢断，所以变量共享是不需要额外的原子操作的。

对于 **任务间共享硬件资源**，例如两个任务都需要使用 spi 读取不同的传感器数据，那么是需要锁操作的，此时不应该使用等待 spi 读取完毕事件来作为锁，以下是一个自旋锁编程样例：

```c
// 两个任务以不同周期读取传感器数据：

volatile uint8_t flag_is_spi_busy = 0;

_async void task1(void){
    uint8_t data;

    while(1){
        // 不断自旋判断变量，直到 spi 空闲
        while(flag_is_spi_busy){
            _yield(); // 调用 yield 短暂出让，相当于 delay_ticks(0);
        }
        // spi 已空闲，上锁
        flag_is_spi_busy = 1;
            _await spi_read_dma(&sensor1, &data);
        // spi 读取完毕，解锁
        flag_is_spi_busy = 0;

        _await spi_read_dma(&sensor1, &data);
        print("%d\n", data);
        _await delay_ticks(100);
    }
}
_async void task2(void){
    uint8_t data;

    while(1){
        // 不断自旋判断变量，直到 spi 空闲
        while(flag_is_spi_busy){
            _yield(); // 调用 yield 短暂出让，相当于 delay_ticks(0);
        }
        // spi 已空闲，上锁
        flag_is_spi_busy = 1;
            _await spi_read_dma(&sensor2, &data);
        // spi 读取完毕，解锁
        flag_is_spi_busy = 0;

        print("%d\n", data);
        _await delay_ticks(20);
    }
}
```

自旋会带来额外的轮询开销，虽然消耗资源不多，但是并不优雅，后续可能会引入互斥锁组件。

## 2、任务与中断间资源

对于 **中断与任务间** 或 **中断与中断间** 共享的变量，需要通过关开中断来保证变量操作的原子性。

任务等待中断的数据应该以 `wait_topic` 事件驱动方式异步等待。为了提高灵活性，目前 ctx 没有内置的队列组件，您可以使用其它的队列库来构建数据队列，然后在中断 push 队列元素后发布事件来通知任务去 pop 队列元素，以下是一个编程样例：

```c
// 中断服务函数
void xxx_irq_handler(void){
    // 队列 push
    my_queue_push(xxx_data_read());
    // 发布事件
    ltx_Topic_publish(&topic_queue)
}

// 任务样例
_async void task1(void){
    uint8_t data;

    while(1){
        // 等待 队列push 事件，超时时间 50 tick
        uint8_t flag_is_timeout = _await wait_topic(&topic_queue, 50);
        if(!flag_is_timeout){ // 其实可以不用判断超时，因为弹出时也会判断是否有元素
            // 等待队列事件成功
            // 不断弹出队列元素
            while(my_queue_pop(&data)){
                // 弹出元素成功
                print("get: %d\n", data);
                _yield(); // 短暂出让
            }
        }
    }
}

// 不太推荐的自旋样例
_async void task1(void){
    uint8_t data;

    while(1){
        if(my_queue_pop(&data)){
            // 弹出元素成功
            print("get: %d\n", data);
        }
        _yield(); // 短暂出让
    }
}
```

或者您也可以自行封装：

```c
_async void my_wait_queue(uint8_t *data){
    
    if(my_queue_pop(&data)){ // 队列已有元素
        return ;
    }else { // 队列没有元素，等待 push 事件
        while(1){
            _await wait_topic(&topic_queue, -1);
            
            if(my_queue_pop(&data)){
                // 弹出元素成功
                return ;
            }
        }
    }
}

// 任务调用自行封装的等待队列数据
// 业务代码更简洁
_async void task1(void){
    uint8_t data;
    while(1){
        _awiait my_wait_queue(&data);
        print("get: %d\n", data);
    }
}
```
